<h3 align="center">
  A customizable slideshow player for images and videos with <i>lots</i> of bells and whistles.
</h3>

![Screenshot](./docs/doc_images/flipflip_home.png)

## Features
- **[Media sources](https://regtemp8.github.io/flipflip/#/v5/sources)** - Use local files or pull from Tumblr, Imgur, DeviantArt, Booru, and more.
- **[Playback features](https://regtemp8.github.io/flipflip/#/v5/playing_scene)** - Control video and audio playback with a dedicated sidebar and context menu actions.
- **[Visual effects](https://regtemp8.github.io/flipflip/#/v5/effects)** - Apply zoom, transitions, cross‑fade, slide, strobe/pulse, fade in/out, panning, and overlay effects.
- **[Grids](https://regtemp8.github.io/flipflip/#/v5/grid)** - Play multiple scenes in a grid with clone and mirror cell options.
- **[Audio](https://regtemp8.github.io/flipflip/#/v5/audio_library)** - Build playlists and organize tracks with the Audio Library.
- **[Organization](https://regtemp8.github.io/flipflip/#/v5/library)** - Library and tagging system to organize sources and generate slideshows.
- **[Captions](https://regtemp8.github.io/flipflip/#/v5/scriptor)** - Caption scripting support for dynamic text overlays.

## Getting Started
New to FlipFlip? The [quick start guide](https://regtemp8.github.io/flipflip/#/quickstart) walks you through creating your first scene, adding sources, and starting playback.
